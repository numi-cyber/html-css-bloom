הסבר לפרויקט HTML+CSS - אתר Bloom

1. פריסת האתר באמצעות פלקס

  • .page - display:flex; flex-direction:column - מסדר את header, האזור האמצעי ו-footer אחד מתחת לשני. min-height:100vh דואג שה-footer תמיד בתחתית.
  • .middle - display:flex; flex-direction:row; gap; flex:1 - מציב את התפריט (aside/nav) בצד ואת main לידו. במסכים קטנים (media query) הופך ל-column.
  • header - display:flex; justify-content:space-between; align-items:center - לוגו מצד אחד וסלוגן מהצד השני.
  • aside ul - flex-direction:column (ובמובייל row + flex-wrap:wrap).
  • .products - flex-wrap:wrap; flex:1 1 250px - כרטיסי מוצרים שעוברים שורה אוטומטית.
  • footer, טופס ההזמנה, דף אודות - גם הם בנויים בפלקס.

תכונות פלקס שבשימוש: display:flex, flex-direction, justify-content, align-items, flex-wrap, gap, flex.

2. נושאים חדשים שנלמדו (למידה עצמית)

  1. מפת תמונה (map, area) - בדף הבית: לחיצה על צד ימין/שמאל של התמונה מובילה לדף זרים או עציצים.
  2. משתני CSS (:root, var()) - בקובץ style.css הוגדרו צבעים, רדיוס וצל פעם אחת, ובשימוש בכל האתר כדי לשמור על עיצוב אחיד.
  3. פריסת גריד (grid) - בדף הבית, שלושת ריבועי היתרונות מסודרים ב-grid-template-columns:repeat(3,1fr).
  4. קישורים מיוחדים - mailto ו-tel ב-footer, וקישור download לקטלוג ה-PDF בדף הבית.
  5. עיצוב מתקדם - object-fit, filter, transform, linear-gradient, border-radius, box-shadow בכרטיסי המוצרים ובכותרת.

3. קבצי העיצוב (CSS)

  • css/style.css - העיצוב המשותף לכל דפי האתר: מבנה הפלקס של הדף, ה-header, תפריט ה-aside, ה-main, כרטיסי המוצרים, הכפתורים, ה-footer, האנימציות ומשתני ה-CSS.
  • עיצוב ששייך לדף אחד בלבד נכתב בקובץ נפרד לכל דף, וכל דף מקשר לשני הקבצים (המשותף + שלו):
    • css/home.css - דף הבית: תמונת הכניסה (position), גריד היתרונות, מפת התמונה.
    • css/about.css - דף אודות: תמונה עגולה לצד טקסט, טבלת שעות הפתיחה, מפת גוגל.
    • css/order.css - דף ההזמנה: עיצוב הטופס וה-fieldset, ובדיקת התקינות הצבעונית.
    • css/bouquets.css ו-css/plants.css - דפי המוצרים: פסקית הפתיחה. כרטיסי המוצרים עצמם נשארו ב-style.css, כי שני הדפים חייבים להיראות אותו דבר.
    • css/thanks.css - דף סיום הפעולה: אנימציית ה-pop.
  • בכל קובץ עיצוב יש גם media query משלו, ולכן כל דפי האתר רספונסיביים.

4. עמידה בדרישות

  • מבנה תיקיות: css, pages, assets/images, assets/media; בתיקייה הראשית רק index.html ו-favicon.ico.
  • דפים: בית, אודות, הזמנה, סיום הזמנה, 2 דפי מוצרים (זרים, עציצים) באותו עיצוב.
  • אנימציות: @keyframes sway (לוגו), fadeUp (main), pop (דף סיום) + transition.
  • position: sticky (header), relative/absolute (תגית "חדש", טקסט על תמונת דף הבית).
  • הטופס: text, email, tel+pattern, number, date, color, range, radio, checkbox, select+optgroup, textarea, required, כפתורי שליחה ואיפוס, שליחה לדף thanks.html.
  • העיצוב לא משתמש ב-id, רק במחלקות, תגיות וסלקטורים מתקדמים (:nth-child, :hover, :invalid, :not, :placeholder-shown).
  • media query בכל דף, גדלים באחוזים.
