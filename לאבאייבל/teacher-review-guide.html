🌸 מדריך הכנה לשיחה עם המורה — פרויקט Bloom

המדריך הזה עובר על כל חלק באתר ומסביר מה הוא עושה ולמה הוא שם, במילים פשוטות. בסוף יש שאלות שהמורה כמעט בטוח ישאל — עם תשובות מוכנות.

1️⃣ מבנה התיקיות — "איפה מה נמצא?"

  • תיקייה ראשית bloom: מכילה רק index.html (דף הבית) ו-favicon.ico (האייקון הקטן בלשונית של הדפדפן) — בדיוק כפי שנדרש.
  • css/: כל קבצי העיצוב. style.css הוא העיצוב המשותף לכל הדפים, ולכל דף יש קובץ משלו (home.css, order.css וכו').
  • pages/: שאר דפי ה-HTML — אודות, זרי פרחים, עציצים, הזמנה, תודה.
  • assets/: קבצים שאינם קוד — תמונות ב-images/ וקטלוג PDF ב-media/.

2️⃣ מבנה ה-HTML של כל דף

כל דף בנוי מאותו "שלד" (דרישה של הפרויקט — מבנה זהה בכל הדפים):

  • <header> — הכותרת העליונה: לוגו שלחיצה עליו חוזרת לדף הבית + סלוגן.
  • <div class="middle"> — האזור המרכזי, מחולק לשניים:
    • <aside> — תפריט הניווט בצד (קישורים לכל הדפים).
    • <main> — התוכן של הדף, מחולק ל-<section> ו-<article>.
  • <footer> — השורה התחתונה: זכויות יוצרים + קישור לאודות + מייל וטלפון.

ב-<head> של כל דף: כותרת הדף (<title>), חיבור לפונטים מ-Google Fonts, וחיבור לשני קבצי CSS — המשותף והייעודי של הדף.

3️⃣ קובץ ה-CSS המשותף (style.css) — החלק הכי חשוב להסביר

משתני CSS (נושא למידה עצמית!)

בראש הקובץ הגדרתי ב-:root משתנים כמו --pink ו---green. במקום לכתוב את הצבע עשרות פעמים, כותבים var(--pink). אם רוצים לשנות צבע בכל האתר — משנים במקום אחד בלבד.

פריסת Flex (לב הפרויקט!)

  • .page { display: flex; flex-direction: column; } — הדף כולו הוא עמודה אחת: כותרת → אמצע → תחתית, אחד מתחת לשני.
  • .middle { display: flex; flex-direction: row; } — האזור המרכזי הוא שורה: התפריט והתוכן עומדים זה לצד זה.
  • flex: 1 על .middle — גורם לאזור האמצעי "להתמתח" ולמלא את כל הגובה הפנוי, כך שה-footer תמיד ב bottom.
  • justify-content: space-between ב-header — דוחף את הלוגו לצד אחד ואת הסלוגן לצד השני.

דברים נוספים שכדאי להכיר

  • position: sticky; top: 0 על ה-header — הכותרת "נדבקת" לראש המסך גם כשגוללים למטה. זו דרישת ה-position.
  • .badge { position: absolute; top: 10px; left: 10px; } — התגית "חדש"/"מבצע" על כרטיסי המוצרים ממוקמת ביחס לכרטיס (שיש לו position: relative).
  • אנימציות (דרישה!):
    • @keyframes sway — הלוגו מתנדנד מצד לצד (סיבוב של 6 מעלות לכל כיוון, בלופ אינסופי).
    • @keyframes fadeUp — התוכן "צף" למעלה ומופיע בהדרגה בכל טעינת דף.
  • סלקטורים מתקדמים: :hover (ריחוף עכבר), :nth-child(even) (כל כרטיס מוצר שני מקבל פילטר צבע), input:checked + label (התווית שמיד אחרי רדיו מסומן).
  • רספונסיביות (דרישה!): @media (max-width: 800px) — מתחת ל-800 פיקסלים .middle הופך מ-row ל-column, כלומר התפריט יורד מתחת לתוכן, והתפריט עצמו הופך לשורה של כפתורים. רוב המידות באתר באחוזים (width: 20% וכו') כדי שהכל יתכווץ יחסית.

4️⃣ דף הבית (index.html) — התבנית הייחודית שלו

  • Hero: תמונה גדולה עם כותרת וכפתור "להזמנה עכשיו" מעליה (עם position).
  • שלושה פיצ'רים (טריות / משלוחים / עיצוב אישי) בשורה — עוד flex.
  • מפת תמונה (נושא למידה עצמית!): <img usemap="#shopmap"> + <map> עם שני <area shape="rect" coords="..."> — לחיצה על צד ימין של התמונה מובילה לזרי פרחים, ועל צד שמאל לעציצים. תמונה אחת, שני קישורים באזורים שונים.
  • קישור הורדה: <a href="assets/media/catalog.pdf" download> — המאפיין download גורם לקטלוג ה-PDF לרדת למחשב במקום להיפתח.

5️⃣ טופס ההזמנה (order.html) — הדף שהכי ישאלו עליו

  • <form action="thanks.html" method="get"> — בשליחה, הנתונים עוברים לדף התודה דרך הכתובת (URL).
  • <fieldset> + <legend> — מקבצים שדות קשורים עם מסגרת וכותרת ("פרטים אישיים", "פרטי ההזמנה").
  • סוגי שדות: text, email, tel, number (עם min/max), date, radio, checkbox, select עם optgroup (קיבוץ אפשרויות ל"זרים" ו"עציצים"), ו-textarea.
  • ולידציה (דרישה!): required = שדה חובה; minlength="2" = שם של לפחות 2 תווים; pattern="0[0-9]{8,9}" = טלפון שמתחיל ב-0 ומכיל 9-10 ספרות. הדפדפן עצמו חוסם שליחה אם משהו לא תקין — בלי JavaScript.
  • בחירת צבע הסרט (הטריק הכי מגניב!): כפתורי רדיו מוסתרים, וה-label שלהם נראה כמו כפתור צבעוני. בעזרת הסלקטור input:checked + label הכפתור הנבחר מקבל מסגרת, ובעזרת ~ .preview פס התצוגה למטה מתצבע בצבע שנבחר ומציג את שמו — הכל ב-CSS בלבד, בלי שורת JavaScript אחת.
  • כפתורי שליחה ואיפוס (דרישה!): type="submit" שולח, type="reset" מנקה את כל השדות.

6️⃣ שני נושאי הלמידה העצמית (מהדפים — חובה להגיד!)

נושא 1 — משתני CSS (:root + var()): למדתי מ-w3schools איך מגדירים צבעים וערכים פעם אחת במקום מרכזי ומשתמשים בהם בכל האתר. השתמשתי בזה ב-style.css לכל פלטת הצבעים של האתר — ככה שינוי צבע אחד מתעדכן בכל הדפים בבת אחת.

נושא 2 — מפת תמונה (<map> + <area>): למדתי איך להפוך אזורים שונים בתמונה אחת לקישורים שונים. השתמשתי בזה בדף הבית: לחיצה על צד אחד של התמונה מובילה לדף זרי הפרחים ועל הצד השני לדף העציצים.

(אם המורה שואל על עוד דברים שלמדת לבד, אפשר להזכיר גם: סלקטור האחים ~ עם :checked בטופס, ו-@keyframes לאנימציות.)

7️⃣ שאלות שהמורה כנראה ישאל — ותשובות מוכנות

❓ "מה זה flex ולמה השתמשת בו?"

Flexbox היא שיטת סידור ב-CSS: הורה מקבל display: flex והילדים שלו מסתדרים אוטומטית בשורה או בעמודה. השתמשתי בו לכל מבנה הדף — העמודה הראשית, השורה של התפריט ליד התוכן, והכותרת. זה גם מה שמאפשר רספונסיביות בקלות: משנים רק את הכיוון מ-row ל-column במסך צר.

❓ "תני 3 מאפייני flex שהשתמשת בהם"

flex-direction (כיוון — שורה/עמודה), justify-content (פיזור לאורך הציר — למשל space-between ב-header), ו-flex-wrap (ירידת שורה אוטומטית בכרטיסי המוצרים ובתפריט במובייל). בונוס: flex: 1 למתיחת האזור המרכזי.

❓ "איפה האנימציה באתר?"

שתי אנימציות: הלוגו ב-header מתנדנד (sway — סיבוב קל לצדדים בלופ), וכל דף נכנס עם fadeUp — התוכן עולה מלמטה ומופיע בהדרגה. שתיהן מוגדרות עם @keyframes ב-style.css.

❓ "איפה השתמשת ב-position?"

בשני מקומות: position: sticky על ה-header כך שהוא נדבק לראש המסך בגלילה, ו-position: absolute על תגיות ה"חדש"/"מבצע" בכרטיסי המוצרים — ממוקמות בפינה ביחס לכרטיס שיש לו position: relative.

❓ "איך עובדת הולידציה בטופס?"

באמצעות מאפיינים של HTML5: required לשדות חובה, type="email" שבודק מבנה מייל, pattern עם ביטוי רגולרי לטלפון ישראלי, ו-min/max לכמות. הדפדפן מונע שליחה ומציג הודעה אם שדה לא תקין — בלי JavaScript.

❓ "איך בחרת צבע הסרט בטופס בלי JavaScript?"

כל צבע הוא כפתור רדיו מוסתר עם label צבעוני. הסלקטור input:checked + label מעצב את הכפתור שנבחר, וסלקטור האחים הכללי ~ משנה את צבע פס התצוגה ואת שם הצבע בהתאם ל-value של הרדיו שסומן.

❓ "איפה הרספונסיביות?"

בכל דף יש @media (max-width: 800px): התפריט והתוכן עוברים משורה לעמודה, התפריט הופך לשורת כפתורים, והסלוגן ב-header מוסתר. בנוסף רוב הרוחבים באחוזים, אז האתר מתכווץ בצורה חלקה בכל גודל מסך.

❓ "למה יש קובץ CSS נפרד לכל דף?"

כי זו דרישה בפרויקט: עיצוב שמשותף לכל הדפים (מבנה, צבעים, כפתורים) נמצא ב-style.css אחד, ועיצוב ששייך רק לדף מסוים (למשל הטופס בדף ההזמנה) נמצא בקובץ משלו. כל דף טוען את שניהם.

❓ "מה זה ה-favicon?"

האייקון הקטן שמופיע בלשונית הדפדפן ליד שם האתר. מחברים אותו ב-<head> עם <link rel="icon" href="favicon.ico">.

❓ "למה לא השתמשת בטבלה לפריסה?"

כי טבלאות מיועדות לנתונים, לא לעיצוב דף. פריסה מודרנית עושים עם flex — זה גמיש, רספונסיבי, ונכון סמנטית. (וזו גם דרישה מפורשת בדפי ההנחיות.)

טיפ אחרון: אם שואלים אותך משהו שלא זוכרת — אל תמציאי. אמרי "בואו נסתכל בקוד ביחד" ופתחי את הקובץ הרלוונטי. המורה רוצה לראות שאת מבינה את המבנה, לא שאת זוכרת כל שורה בעל פה. בהצלחה! 🌸
